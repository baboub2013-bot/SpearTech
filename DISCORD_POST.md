# 🔱 Spear Tech 2.0 — Meteor Client 26.2

Spear Tech is a spear-focused Meteor addon with combat, movement and visual utilities built to feel native to Meteor Client.

**Modules**
• Spear Swap
• Lunge Boost
• Spear Reach
• One Shot
• Spear Cooldown
• Spear Velocity
• Spear Range Preview

**HUD**
• Spear Status — live charge, reach and Lunge level

**Requirements**
• Minecraft 26.2
• Meteor Client 26.2
• Fabric Loader 0.19.3+
• Java 25

Drop the JAR into your `mods` folder and open the **Spear Tech** category in Meteor ClickGUI.
