# Discord release checklist

1. Install JDK 25.
2. Run `BUILD.bat`.
3. Confirm `build\libs\spear-tech-2.0.0.jar` exists.
4. Launch Minecraft 26.2 with Meteor Client 26.2 and the Spear Tech JAR.
5. Confirm the **Spear Tech** category appears.
6. Open HUD editor and confirm **Spear Status** appears.
7. Test every module once before posting the JAR.
8. Copy the text from `DISCORD_POST.md` into your Discord release channel.
9. Attach `spear-tech-2.0.0.jar`.
10. Link this source repository so users can inspect the code.
